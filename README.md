
# Career Navigator

Career Navigator is a React application to guide students and To guide students and job seekers toward suitable career paths by providing career recommendations based on categories of interest and market demand


## Description

the system provides generalized career guidance:

Students select a category/technology of interest (e.g., Data Science, Web Development, Cybersecurity).

The system recommends career roles within that category.

Each role is explained with growth opportunities, required skills, and market demand trends.Career selection involves selection of technologies of interest, skimming through the available roles and opportunites for the technology and the growth opportunites the chosen path would provide. The goal is to collect data from the students about their skills, techologies of interest,or their resume and provide them with the career opportunites available for them and the growth opportunites of those opportunites based on the changing market trends and demand of those skills in the present market. 

Example Career Recommendations

| Category | Recommended Roles | Growth Path Example |
| --- | --- | --- |
| **Data Science** | Data Analyst, ML Engineer, AI Researcher | Analyst → Scientist → Research Lead |
| **Web Development** | Frontend Developer, Backend Developer, Full-Stack Engineer | Junior Dev → Senior Dev → Architect |
| **Cybersecurity** | Security Analyst, Ethical Hacker, Security Architect | Analyst → Specialist → CISO |
| **Cloud Computing** | Cloud Engineer, DevOps Specialist, Cloud Architect | Engineer → Architect → Cloud Consultant |
| **AI/ML** | ML Engineer, AI Product Manager, Research Scientist | Engineer → Lead → Research Director |

## Installation

Install my-project with npm

```bash
  npm install 
  cd carrer_navigator
```
    
## Run Locally

Go to the project directory

```bash
  cd career_navigator
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```
